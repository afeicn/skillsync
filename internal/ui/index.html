把你的 AI 技能，跟着你走

skillsync 把你的 Agent 技能库在多台电脑之间自动同步。
在任意一台电脑上改的技能，另一台几分钟后就有了；改冲突了，它会请你决定，绝不擅自覆盖。
需要一个 Git 仓库存放技能（GitHub / GitLab 私有仓库均可）。还没有？去 github.com/new 建一个空仓库，30 秒搞定。
每 5 分钟 每小时（推荐） 每天
